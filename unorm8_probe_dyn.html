WebGL UNORM8 conversion probe

FP32 values from 64 ULP below to 64 ULP above every 8-bit half-way boundary are rendered through the visible canvas, whose size, tile order and background change on every run. The signature is the SHA-256 of the extracted conversion features (not of the pixels), so it stays identical as long as the GPU converts the same way.
